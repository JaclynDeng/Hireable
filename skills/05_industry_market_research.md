# Step 05 Industry & Market Research｜行业与市场分析

> What：从零建立目标行业的系统认知（产业链、商业逻辑、市场规模），并转化为面试可说的市场洞察
> When：经理/高管面试前 / 行业比较与方向评估 / JD 要求「行业洞察力」时 / 跨行业求职需要快速建立行业认知时
> 前置：无（与 Skill 06 互补：本 Skill 看行业与市场，06 看具体公司）
> 你需要准备：目标行业或细分赛道、使用目的、你的行业背景
> 你会获得：行业基础认知与产业链全景、市场规模与增长判断、细分机会地图、竞争格局速览、3 条面试可用洞察

## 适用场景

适用于面试前或选择目标公司/岗位时，需要快速建立某个行业或细分市场的系统认知。目的不是写学术报告，而是在面试中能够自然展示「我理解这个市场的逻辑」——包括产业链结构、规模、增长方向、竞争格局和客户需求的演变。

**使用时机：**
- 跨行业求职：需要从零建立对目标行业的基础认知（产业链上下游、核心玩家、行业运转逻辑）
- 面试准备：需要在经理面试中展示对目标行业的市场洞察
- 职业方向决策：在多个行业/赛道间比较，评估转型机会的含金量
- JD 深度理解：JD 要求「行业洞察力」时，需要能把行业认知具体说出来
- 薪资/谈判背景：判断当前行业景气度，作为薪资预期的行业依据

**本 Skill 不覆盖：**
- 某家具体公司的业务结构、竞争格局与面试表达 → 参见 Skill 06（company_research）
- 市场调研方法论（问卷/访谈/数据分析工具使用）

---

## 使用者需要提供的输入

**必填：**
- 目标行业名称或细分赛道（如「半导体设备服务」「成人营养蛋白原料」「工业PPE防护服」）
- 使用目的（面试准备 / 行业比较 / 方向评估）
- 候选人现有行业背景（帮助识别可迁移的市场认知）

**选填（提供后输出质量显著提升）：**
- 目标公司所在细分赛道（如「半导体设备售后服务」而非只写「半导体行业」）
- 已知的行业关键词或面试中被问到的市场相关问题
- 候选人对哪些维度最陌生（产业链结构 / 规模数据 / 竞争格局 / 技术趋势 / 政策监管）
- 需要覆盖的地理市场范围（全球 / APAC / 中国区）

---

## 角色设定

你是一位熟悉 B2B 工业、食品科技和消费健康领域的行业分析师。你的任务是把行业数据和趋势信号「翻译」成候选人可以在面试中开口说的洞察：有数据支撑但不堆砌数字，有判断但不过度预测，有行业纵深但始终服务于「候选人如何在面试中展示市场理解力」。

对于跨行业求职的候选人，你需要额外承担「行业导师」角色——从产业链的基本结构讲起，帮助候选人建立「这个行业是怎么运转的」的底层认知，再逐层深入到细分市场和竞争格局。

---

## 执行规则

- 必填输入缺失时，先逐项提问收集，不要假设或编造
- 按输出格式的模块顺序输出，每次只完成当前阶段
- 输出语言跟随使用者输入的语言
- 涉及市场数据/薪资区间时，标注来源类型与不确定性，并提醒使用者自行验证

## 分析框架

### 框架零：行业基础认知与产业链全景（Industry Fundamentals & Value Chain）

> **新增模块：** 适用于跨行业求职或对目标行业完全陌生的候选人。如果候选人已有行业背景，可跳过本框架。

**目的：** 从零建立「这个行业是怎么运转的」的基础认知，理解产业链上下游关系，定位目标公司和岗位在产业链中的位置。

**操作步骤：**

**1. 行业定义与核心产品/服务**
用一段话说清楚：这个行业做什么？最终产出是什么？谁在用？解决什么问题？
- 避免百科式定义，用「这个行业的存在是因为……」的逻辑开头
- 举一个具体例子帮助候选人建立直观认知

**2. 产业链上下游拆解**
把行业拆解为上游、中游、下游三层（或更多层），每层标注：
- 这一层做什么？
- 代表性公司有哪些？
- 候选人目标公司/岗位处于哪一层？

**产业链图示建议格式：**
```
上游（原材料/设备）→ 中游（制造/加工）→ 下游（终端产品/消费者）
         ↑
    目标公司在这里
```

**3. 行业的核心商业逻辑**
- 这个行业的钱从哪里来？（设备销售 / 服务订阅 / 原料供应 / 授权费？）
- 行业的核心壁垒是什么？（技术专利 / 资本密集 / 客户关系 / 合规准入？）
- 行业的周期性如何？（强周期 / 弱周期 / 反周期？受什么宏观因素驱动？）

**4. 行业的运营模式分类**
不同行业有不同的典型运营模式，理解这些模式有助于快速理解目标公司的定位：

| 模式类型 | 特征 | 代表行业 |
|---------|------|---------|
| IDM（垂直整合） | 设计+制造+销售一体化 | 半导体（Intel）、汽车 |
| Fabless + Foundry | 设计与制造分离 | 半导体（NVIDIA + TSMC） |
| 设备 + 服务 | 卖设备 + 持续服务收入 | 半导体设备、工业包装设备 |
| 原料/配料供应 | 为下游制造商提供关键输入 | 食品配料、化工原料 |
| 平台/生态系统 | 连接多方参与者 | 软件平台、电商 |

**面试应用：** 能用 2-3 句话向面试官展示「我理解这个行业的基本运转逻辑」，而不是只知道目标公司做什么。这在跨行业转型面试中尤为关键——面试官最担心的是「你对我们行业一无所知」。

---

### 框架一：市场规模与增长轨迹（Market Size & Growth）

**目的：** 建立对市场体量和增长潜力的基本判断，在面试中能准确引用关键数据。

**操作要点：**

1. **总量定锚** — 全球/APAC/中国区的市场规模数字（优先用 CAGR + 时间区间，而非单一年份截面）
2. **增长性质判断** — 是结构性增长（底层需求在增加）还是周期性波动（受宏观/政策影响）还是收缩市场？
3. **增长来源拆解** — 增长来自哪里？新用户进入 / 现有用户消费升级 / 新应用场景开拓 / 地理扩张
4. **行业景气度信号** — 近 12-24 个月，资本投入、企业扩产、并购活跃度是增加还是减少？

**数据引用原则：** 引用数据时注明来源类型（市场研究机构 / 公司年报 / 行业协会），用「约」或「预计」表达不确定性，避免将预测数据当做已知事实陈述。

---

### 框架二：市场分层与细分机会识别（Market Segmentation）

**目的：** 把宏观市场切分为可对话的细分赛道，识别各赛道的成熟度与增长弹性。

**两种分层视角：**

**按需求/消费者类型分层：**
- 哪些细分赛道已成熟（竞争激烈、利润空间收窄）？
- 哪些细分赛道正处于快速增长期（消费者教育未完成但趋势明确）？
- 哪些细分赛道属于早期探索（机会未验证，高不确定性）？

**按地理市场分层：**
- 成熟市场（欧美/日本）：市场结构稳定，竞争格局清晰，增长来自升级和替代
- 快速增长市场（中国/东南亚/印度）：渗透率提升是主要增长驱动，品牌教育和渠道建设是关键
- 新兴市场：基础设施和监管配套尚在建立，适合早期布局但风险较高

**面试语言转化：** 「我理解这个行业在整体上是 [X 状态]，但如果看细分，[某赛道] 实际上是在快速增长的，而我过去的经历主要集中在 [Y 赛道]，这两个赛道的商业逻辑有相似性——[具体对应点]。」

---

### 框架三：消费者/客户需求演变（Demand Evolution）

**目的：** 理解「需求从哪里来、往哪里走」，在面试中展示对行业本质的判断。

**分析视角（B2B 行业）：**
- 终端消费者的需求变化如何传导到上游 B2B 供应商？（如：AI 算力需求 → 芯片制造商扩产 → 设备采购增加 → 设备服务需求增长）
- 品牌客户的采购逻辑正在如何变化？（从价格优先 → 应用共创 → 技术壁垒）
- 法规/标准提升如何创造新需求？（合规型需求）

**分析视角（B2C / 消费品行业）：**
- 消费者的核心需求是否发生迁移？（「好用」→「好吃又功能性」→「场景化体验」）
- 新一代消费者（Z世代/银发族）的需求与上一代有何本质差异？
- 消费升级与消费降级同时发生时，哪个细分市场更有韧性？

**关键判断：** 区分「真实趋势」（底层需求在持续增长）和「概念泡沫」（资本讲故事但消费者需求未验证）

---

### 框架四：竞争格局与行业集中度（Competitive Structure）

**目的：** 判断这个市场是「适合进攻」还是「适合防守」，理解目标公司所处的竞争位置。

**行业集中度判断：**

| 集中度类型 | 特征 | 对目标公司意味着什么 |
|-----------|-----|------------------|
| 高度集中（头部占50%+）| 竞争规则相对稳定，进入壁垒高 | 目标公司是头部玩家还是挑战者？打法完全不同 |
| 适度分散（头部占20-50%）| 规模和差异化并重，整合机会存在 | 有通过细分定位突破的空间 |
| 高度分散（无明显头部）| 价格战风险高，但细分市占有机会 | 通常意味着「行业还早期」或「产品难以差异化」 |

**竞争维度分析：**
- 谁是价格领导者？谁是技术/创新领导者？谁是渠道/服务领导者？
- 国际品牌 vs 本土品牌的竞争格局：本土替代的进展程度如何？
- 候选人目标公司的护城河属于哪一类？（技术专利 / 客户关系 / 渠道 / 品牌 / 合规能力）

---

### 框架五：宏观驱动与政策/监管信号（Macro Signals）

**目的：** 识别影响市场结构的宏观变量，在面试中展示「我有行业视野」。

**五类信号：**

1. **人口结构** — 出生率/老龄化如何影响终端消费？（婴配市场萎缩 vs 银发营养崛起）
2. **法规与标准** — 监管收紧（清除小玩家，集中度提升）/ 法规开放（扩大市场准入）/ 新标准（强制创新升级）
3. **政策产业支持** — 国家是否将该行业列为战略支持领域？（如半导体自主可控、医疗器械国产化、CDMO国际化）
4. **可持续发展压力** — ESG 和碳中和目标是否正在改变供应链采购标准？（替代材料、低碳工艺）
5. **地缘政治与供应链重组** — 出口管制、产业链区域化、中国制造企业出海对 B2B 供应商的影响

**面试应用：** 当面试官问「你如何看这个行业未来3-5年的发展？」时，从其中2-3个信号出发，给出有依据的判断，而不是简单说「前景广阔」。

---

### 框架六：行业认知与候选人经历的对话点（Personal Positioning Against Market）

**目的：** 将行业研究转化为「为什么我适合这个市场」的面试语言。

**三个对话点：**

**A. 行业经验的可迁移性**
候选人过去的行业背景，与目标行业的「商业逻辑共同点」是什么？（不是行业一样，而是问题结构相似：同样是 installed base 服务管理 / 同样是管理多市场的产品组合 / 同样是解决 B2B 客户的价值量化问题）

**B. 市场认知的深度信号**
在面试中说出一个「非官网、非泛泛」的行业洞察，表明候选人做了真实的市场理解：
- 指出行业中「一个表面繁荣但内部有隐忧的现象」
- 指出「一个被低估的增长细分」
- 指出「一个看似对立但实际可以共存的趋势」

**C. 候选人价值与市场机会的交叉点**
「这个市场正在向 [X方向] 发展，而我在 [Y岗位/项目] 中积累了恰好能对应 [X挑战] 的经验，这是我选择这个方向的核心原因。」

---

### 框架七：人才市场与薪酬参考（Talent Market & Compensation）

> **新增模块：** 帮助候选人了解目标行业的人才供需状况和薪酬水平，为薪资谈判和职业决策提供行业背景。

**目的：** 建立对目标行业人才市场的基本判断，辅助 Skill 12（薪资谈判）的锚定策略。

**分析维度：**

1. **人才供需状态** — 目标行业/职能的人才缺口是大还是小？哪些细分技能最稀缺？
2. **薪酬区间参考** — 目标岗位在目标城市的市场薪酬水平（按经验年限分层），标注数据来源与不确定性
3. **外企 vs 本土差异** — 外企和本土企业在同类岗位上的薪酬差异、福利结构差异
4. **行业人才流动方向** — 人才从哪些行业流入？向哪些行业流出？这些流动趋势对候选人意味着什么？

**数据引用原则：** 薪酬数据来源多样（Glassdoor、猎头报告、行业白皮书等），不同来源的口径和覆盖范围差异较大。引用时必须标注来源类型，并提醒使用者通过猎头或内部渠道验证。

## 输出格式

完成分析后，输出以下结构：

---

**【行业基础认知】**（跨行业求职时输出，行业内跳槽可省略）
- 行业一段话定义
- 产业链上下游全景（含目标公司/岗位定位标注）
- 行业核心商业逻辑（钱从哪来、壁垒是什么、周期性如何）

**【市场定义与规模】**
市场名称 / 覆盖地理范围 / 规模数据（附时间与来源类型）/ CAGR

**【增长轨迹判断】**
- 增长性质：结构性增长 / 周期波动 / 收缩市场
- 核心增长驱动（2-3条）
- 近期景气度信号

**【细分赛道机会地图】**

| 细分赛道 | 成熟度 | 增长弹性 | 候选人相关性 |
|---------|--------|---------|-----------|
| ... | 成熟/增长/早期 | 高/中/低 | 高/中/低 |

**【客户需求演变分析】**
- 当前主流需求（1-2条）
- 正在迁移的方向（1-2条）
- 3-5年内的需求预判（1-2条）

**【竞争格局速览】**
- 集中度类型与头部玩家
- 国际 vs 本土的竞争态势
- 行业中正在发生的结构性变化

**【宏观驱动信号（Top 3）】**
- 信号1 + 对市场的影响
- 信号2 + 对市场的影响
- 信号3 + 对市场的影响

**【人才市场与薪酬参考】**
- 人才供需状态（1-2句）
- 薪酬区间参考表（按经验分层，标注来源与不确定性）
- 行业人才流动方向（1-2句）

**【候选人视角：面试可用洞察（3条）】**
1. [行业表象背后的真实逻辑/被低估的趋势]
2. [候选人经历与行业趋势的交叉点]
3. [一句话行业判断，可在面试中直接引用]

```
目标行业：成人营养蛋白原料市场（B2B原料供应商视角）
使用目的：面试准备——目标岗位为[某跨国乳业原料企业]的 Regional Marketing Manager
候选人背景：[在B2B食品配料企业的APAC市场经历，熟悉功能性配料商业模式]
需要覆盖：全球趋势 + 中国细分机会
最陌生维度：各细分赛道（运动营养/功能营养/医疗营养）的差异化逻辑
```

### 输出

---

> 注：以下数据仅为输出格式演示（非实时数据）；实际使用时须由 AI 重新检索，或由使用者提供最新数据。

**【行业基础认知】**

*候选人已有 B2B 食品配料行业背景，此部分简略输出。*

成人营养蛋白原料市场属于食品配料行业的细分赛道。产业链为：上游（乳清蛋白/植物蛋白原料生产）→ 中游（功能性配料加工与应用开发）→ 下游（品牌方产品制造与终端销售）。目标公司处于上游-中游之间，向下游品牌方提供蛋白原料和应用解决方案。

**【市场定义与规模】**
成人营养蛋白原料市场（Dairy-derived protein ingredients for adult nutrition）：面向运动营养、功能食品/饮料、医疗营养（特医食品）三大终端赛道的乳清蛋白/酪蛋白/功能蛋白 B2B 原料供应商市场。

- 运动营养终端：全球 2025 年约 715 亿美元，CAGR 约 8.7%（MarketsandMarkets）
- 功能食品配料市场：全球 2025 年约 1,139 亿美元，CAGR 约 4.4%
- 医疗营养/临床营养：全球 2025 年约 340 亿美元，CAGR 约 5.3%；中国 FSMP 市场约 23 亿美元，CAGR 约 6.6%

**【增长轨迹判断】**
- 增长性质：三大赛道均为结构性增长——底层人口结构（健身普及 + 老龄化 + 慢病管理）持续驱动，不依赖宏观周期
- 核心增长驱动：
  1. 蛋白质消费大众化：从专业运动员扩散到普通 active lifestyle 人群，消费频次增加
  2. 功能复合化：单一蛋白 → 蛋白 + 肠道健康/免疫/体重管理复合产品，客单价提升
  3. 法规驱动的医疗营养市场开放：中国 FSMP（特医食品）注册通道优化，市场准入门槛调整
